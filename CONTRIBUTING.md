# Contributing

Keep changes small, Azure-only, and grounded in official Microsoft Learn sources.

## Rules

- Link to Microsoft Learn for credential status, exam scope, and learning content.
- Do not add exam dumps or unofficial assessment material.
- Do not describe a recommended sequence as a formal prerequisite.
- Do not label an associate credential as expert.
- Avoid repeating credential details in multiple files.
- Remove or clearly mark retired credentials.
- Run the Markdown link check before submitting a change.

## Updating a credential

Include:

- Credential name and level.
- Current exam code and title.
- Credential page.
- Current study guide.
- Required prerequisites, if any.
- A short transition note when replacing a retired exam.
