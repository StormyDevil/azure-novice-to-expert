# Stage 0: Azure foundation

## Goal

Build enough Azure vocabulary to discuss cloud concepts, core services, management, governance, pricing, and support with customers and delivery teams.

## Certification

### Microsoft Certified: Azure Fundamentals

- Exam: AZ-900, Microsoft Azure Fundamentals.
- Level: Beginner.
- Credential: [Azure Fundamentals](https://learn.microsoft.com/credentials/certifications/azure-fundamentals/).
- Exam scope: [AZ-900 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-900).
- Preparation: [AZ-900 course and learning paths](https://learn.microsoft.com/training/courses/az-900t00).

## Exit criteria

Before moving to infrastructure, be able to:

- Compare IaaS, PaaS, and SaaS.
- Explain Azure regions, availability zones, subscriptions, resource groups, and management groups.
- Identify common compute, network, storage, database, identity, security, and monitoring services.
- Explain shared responsibility, consumption pricing, governance, and service-level agreements.
- Navigate the Azure portal and understand the purposes of Azure CLI, PowerShell, ARM, and Bicep.

AZ-900 is the common foundation. The later DP-900 and AI-901 fundamentals credentials belong to their specialist tracks rather than being prerequisites for infrastructure.
