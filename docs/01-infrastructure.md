# Stage 1: Infrastructure

## Goal

Move from Azure fundamentals to operating Azure environments and designing production-ready solutions.

## 1. Azure Administrator Associate

- Exam: AZ-104, Microsoft Azure Administrator.
- Level: Intermediate.
- Credential: [Azure Administrator Associate](https://learn.microsoft.com/credentials/certifications/azure-administrator/).
- Exam scope: [AZ-104 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-104).
- Focus: identities and governance, storage, compute, virtual networking, and monitoring.

This is the core hands-on infrastructure credential and a required certification prerequisite for Azure Solutions Architect Expert.

### Recommended Applied Skills

- [Deploy and administer Linux virtual machines on Microsoft Azure](https://learn.microsoft.com/credentials/applied-skills/deploy-and-administer-linux-virtual-machines-on-microsoft-azure/).
- [Secure storage for Azure Files and Azure Blob Storage](https://learn.microsoft.com/credentials/applied-skills/secure-storage-azure-files-azure-blob-storage/).
- [Deploy and configure Azure Monitor](https://learn.microsoft.com/credentials/applied-skills/deploy-and-configure-azure-monitor/).

## 2. Optional networking depth

### Azure Network Engineer Associate

- Exam: AZ-700, Designing and Implementing Microsoft Azure Networking Solutions.
- Level: Intermediate.
- Credential: [Azure Network Engineer Associate](https://learn.microsoft.com/credentials/certifications/azure-network-engineer-associate/).
- Exam scope: [AZ-700 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-700).

AZ-700 is recommended for architects who design hybrid connectivity, application delivery, private access, routing, and network security. It is not a prerequisite for AZ-305.

Applied Skills option:

- [Configure secure access to your workloads using Azure networking](https://learn.microsoft.com/credentials/applied-skills/configure-secure-workloads-use-azure-virtual-networking/).

## 3. Azure Solutions Architect Expert

- Exam: AZ-305, Designing Microsoft Azure Infrastructure Solutions.
- Level: Expert certification.
- Credential: [Azure Solutions Architect Expert](https://learn.microsoft.com/credentials/certifications/azure-solutions-architect/).
- Exam scope: [AZ-305 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-305).
- Required prerequisite: earn Microsoft Certified: Azure Administrator Associate.

Focus on design decisions across identity, governance, monitoring, data storage, business continuity, and infrastructure.

## Exit criteria

Be able to turn business and technical requirements into:

- Subscription and management-group organization.
- Identity, access, policy, and governance design.
- Network topology and connectivity design.
- Compute and storage selection.
- Availability, backup, disaster recovery, and monitoring design.
- Cost, reliability, security, operational excellence, and performance trade-offs.
