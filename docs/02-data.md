# Stage 2: Data

## Goal

Understand Azure data workloads, then develop practical depth in designing and operating Azure SQL solutions.

## 1. Azure Data Fundamentals

- Exam: DP-900, Microsoft Azure Data Fundamentals.
- Level: Beginner.
- Credential: [Azure Data Fundamentals](https://learn.microsoft.com/credentials/certifications/azure-data-fundamentals/).
- Exam scope: [DP-900 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/dp-900).
- Focus: relational and non-relational data, transactional and analytical workloads, and Azure data services.

DP-900 is recommended preparation, not a formal prerequisite for DP-300.

## 2. Azure Database Administrator Associate

- Exam: DP-300, Administering Microsoft Azure SQL Solutions.
- Level: Intermediate.
- Credential: [Azure Database Administrator Associate](https://learn.microsoft.com/credentials/certifications/azure-database-administrator-associate/).
- Exam scope: [DP-300 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/dp-300).
- Focus: planning, deployment, security, monitoring, performance, automation, and high availability for Azure SQL.

### Recommended Applied Skills

- [Develop data-driven applications by using Microsoft Azure SQL Database](https://learn.microsoft.com/credentials/applied-skills/develop-data-driven-applications-by-using-microsoft-azure-sql-database/).
- [Configure and migrate to Azure Database for PostgreSQL](https://learn.microsoft.com/credentials/applied-skills/configure-and-migrate-to-azure-database-for-postgresql/).

## Architecture outcomes

Be able to:

- Choose between relational, document, key-value, object, and analytical stores.
- Explain operational versus analytical workload characteristics.
- Design Azure SQL deployment, security, resiliency, monitoring, and migration approaches.
- Identify when Azure SQL, Azure Database for PostgreSQL, Azure Cosmos DB, or Azure Storage fits a requirement.
- Define recovery, retention, encryption, access-control, and performance requirements.

## Scope note

DP-100 retired on 1 June 2026. Its successor is covered in the [AI track](03-ai.md) because the replacement credential centers on machine learning and generative AI operations. Microsoft Fabric credentials are intentionally excluded from this Azure-only path.
