# Stage 3: AI

## Goal

Progress from Azure AI concepts to building AI applications and operating machine learning and generative AI systems on Azure.

## 1. Azure AI Fundamentals

- Exam: AI-901, Microsoft Azure AI Fundamentals.
- Level: Beginner.
- Credential: [Azure AI Fundamentals](https://learn.microsoft.com/credentials/certifications/azure-ai-fundamentals/).
- Exam scope: [AI-901 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/ai-901).

AI-901 replaced AI-900. It is recommended preparation, not a formal prerequisite for AI-103.

## 2. Azure AI Engineer Associate

- Exam: AI-103, Developing AI Apps and Agents on Azure.
- Level: Intermediate.
- Credential: [Azure AI Engineer Associate](https://learn.microsoft.com/credentials/certifications/azure-ai-engineer/).
- Exam scope: [AI-103 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/ai-103).
- Focus: developing, deploying, integrating, securing, and monitoring AI applications and agents on Azure.

AI-103 replaced the retired AI-102 exam.

### Recommended Applied Skills

- [Implement knowledge mining with Azure AI Search](https://learn.microsoft.com/credentials/applied-skills/implement-knowledge-mining-with-azure-ai-search/).
- [Develop generative AI solutions with Azure OpenAI Service](https://learn.microsoft.com/credentials/applied-skills/develop-generative-ai-solutions-with-azure-openai-service/).
- [Build a natural language processing solution with Azure AI Language](https://learn.microsoft.com/credentials/applied-skills/build-natural-language-solution-azure-ai/).

## 3. Machine Learning Operations Engineer Associate

- Exam: AI-300, Operationalizing Machine Learning and Generative AI Solutions.
- Level: Intermediate.
- Credential: [Machine Learning Operations Engineer Associate](https://learn.microsoft.com/credentials/certifications/operationalizing-machine-learning-and-generative-ai-solutions/).
- Exam scope: [AI-300 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/ai-300).
- Focus: MLOps, GenAIOps, infrastructure as code, model and application lifecycle, quality, observability, and optimization.

Applied Skills option:

- [Train and manage a machine learning model with Azure Machine Learning](https://learn.microsoft.com/credentials/applied-skills/train-and-deploy-a-machine-learning-model-with-azure-machine-learning/).

## Exit criteria

Be able to:

- Select appropriate Azure AI services for a workload.
- Design grounded, observable, secure AI applications and agents.
- Explain model and application evaluation, responsible AI, content safety, and human oversight.
- Design repeatable deployment and monitoring for machine learning and generative AI systems.
- Describe data, identity, networking, cost, latency, and operational trade-offs.
