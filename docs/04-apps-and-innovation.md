# Stage 4: Apps and innovation

## Goal

Develop Azure applications, choose suitable hosting and integration services, and progress to expert-level DevOps practices.

## 1. Azure Developer Associate

- Exam: AZ-204, Developing Solutions for Microsoft Azure.
- Level: Intermediate.
- Credential: [Azure Developer Associate](https://learn.microsoft.com/credentials/certifications/azure-developer/).
- Exam scope: [AZ-204 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-204).
- Focus: compute, storage, security, monitoring, troubleshooting, APIs, and event- and message-based integration.

### Recommended Applied Skills

- [Deploy cloud-native apps using Azure Container Apps](https://learn.microsoft.com/credentials/applied-skills/deploy-cloud-native-apps-using-azure-container-apps/).
- [Deploy containers by using Azure Kubernetes Service](https://learn.microsoft.com/credentials/applied-skills/deploy-containers-by-using-azure-kubernetes-service/).
- [Automate Azure Load Testing by using GitHub Actions](https://learn.microsoft.com/credentials/applied-skills/automate-azure-load-testing-by-using-github-actions/).

## 2. DevOps Engineer Expert

- Exam: AZ-400, Designing and Implementing Microsoft DevOps Solutions.
- Level: Expert certification.
- Credential: [DevOps Engineer Expert](https://learn.microsoft.com/credentials/certifications/devops-engineer/).
- Exam scope: [AZ-400 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-400).
- Required prerequisite: earn either Azure Administrator Associate or Azure Developer Associate.

Focus on source control, build and release pipelines, security and compliance, instrumentation, and continuous feedback.

## Exit criteria

Be able to:

- Choose among Azure App Service, Functions, Container Apps, and AKS.
- Design identity, configuration, secrets, data access, messaging, and observability for applications.
- Design APIs and asynchronous integration using appropriate Azure services.
- Establish infrastructure and application delivery pipelines with quality and security controls.
- Define deployment, rollback, reliability, performance, and operational feedback strategies.
