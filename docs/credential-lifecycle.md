# Credential lifecycle

Microsoft updates, replaces, and retires credentials. Validate the path before committing training budget or booking an exam.

## Before each exam

1. Open the credential page linked from the relevant track.
2. Confirm that the exam is available in the learner's region and language.
3. Read the current study guide and note its “skills measured” date.
4. Check the [credential retirement page](https://learn.microsoft.com/credentials/support/credential-retirement).
5. Check the [exam and assessment lab retirement page](https://learn.microsoft.com/credentials/support/retired-certification-exams).
6. Use Microsoft's practice assessment when one is linked from the credential page.

## Repository review

Review this repository at least quarterly and whenever Microsoft announces a credential change.

For each review:

- Remove retired credentials from the active route.
- Add an explicit transition note when an exam is replaced.
- Confirm certification prerequisites.
- Recheck every certification, study guide, and Applied Skills page.
- Update the “checked” date in the root README.
